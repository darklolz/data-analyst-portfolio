# Abhishek Khandwal - Data Analyst Portfolio

Modern responsive portfolio website for a Data Analyst profile.

## Structure

```text
data-analyst-portfolio/
  index.html
  css/
    styles.css
  js/
    script.js
  assets/
    project-sales.svg
    project-netflix.svg
    project-churn.svg
    project-sql.svg
    Abhishek-Khandwal-Resume.pdf
```

## Customize Before Publishing

1. Replace `assets/Abhishek-Khandwal-Resume.pdf` with your real resume using the same file name.
2. Replace placeholder email, GitHub, and LinkedIn links in `index.html`.
3. Replace `#` project buttons with your actual GitHub repositories and live demo links.
4. Update certifications with real certificate names, dates, and URLs.

## Deploy On GitHub Pages

1. Create a new GitHub repository, for example `data-analyst-portfolio`.
2. Upload all files from this folder to the repository.
3. Go to repository `Settings`.
4. Open `Pages`.
5. Under `Build and deployment`, choose `Deploy from a branch`.
6. Select branch `main` and folder `/root`.
7. Click `Save`.
8. Your portfolio will be live at `https://your-username.github.io/data-analyst-portfolio/`.

## Local Preview

Open `index.html` in a browser, or use a small local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
